Invoice Viewer Help

What does † mean?
† means this value already includes GST.

Why can totals differ by 1 cent?
GST can be rounded at different steps:

  • Customer-style grouped GST (recommended): sums the server's ex-GST amount, applies 10% GST to that grouped amount, then rounds the displayed total to 2 decimals.
  • Invoice-reconciled source data: keeps the underlying invoice allocation logic, but displayed server totals still use grouped GST rounding for consistency.

Decimal rounding
Displayed values use standard 2-decimal rounding. For grouped server totals, the tooltip also shows the 10% GST working before rounding. Example: 81.719 → 81.72 and 81.714 → 81.71.

Tip
For customer/accounting-style server totals, use Customer-style grouped GST.
